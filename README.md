# Student Performance Analysis using Exploratory Data Analysis

## Project Overview

This project analyzes student academic performance using Exploratory Data Analysis (EDA) techniques.

The dataset contains information about student attendance, study hours, assignment marks, final marks, gender, and CGPA.

## Objectives

* Analyze student academic performance.
* Study the relationship between attendance and final marks.
* Analyze the relationship between study hours and final marks.
* Compare assignment marks with final marks.
* Analyze gender-wise performance.
* Identify top-performing and low-performing students.
* Detect missing values and potential anomalies.
* Analyze correlations between numerical variables.
* Classify students into different performance categories.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains 15 student records with the following columns:

* Student_ID
* Gender
* Attendance
* Study_Hours
* Assignment_Marks
* Final_Marks
* CGPA

## Key Insights

The analysis helps understand how attendance, study hours, assignment marks, and CGPA are related to final academic performance.

Students were also classified into different performance categories to identify students performing well and students who may need additional academic support.

## Conclusion

This project demonstrates how Exploratory Data Analysis can be used to understand student academic performance through statistical analysis and data visualization.
